# Rapperle agent guidance

- After completing requested changes, run the relevant checks, commit the changes, and push to `main` so the Vercel deployment starts, unless the user explicitly asks to keep the work local or use another branch. Check the deployment result and report any failure.
- Album clues must not contain the rapper's name, a recognizable part of their stage name, or an accepted alias. Use another album, or an EP or mixtape when needed. Run the roster validation before pushing.
